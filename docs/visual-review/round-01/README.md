# Rating round 1: vista compositions (task 05b)

**What you are rating:** composition only, meaning how much vastness each layout *could* carry. These are structure-only debug images. Colors are region codes, and there is no haze, value design, paint or texture yet (tasks 06–07 add those). Please ignore the cartoon look and judge the *arrangement*: size, height, depth, framing and sky.

- `candidates-regions.png`: 16 cells, numbered 0–15 left to right and top to bottom (row 1 is 0–3). Colors: sky blue, clouds white, distant range lavender, mountain gray, valley spurs and near ridges brown, water blue, shore tan, woodland green, rocks and cliff edge orange.
- `candidates-flat.png`: the same cells as neutral values.

All cells are 16:9 with default form settings, generated by the lakeshore generator (v0) on 2026-09-26.

## How to rate

For each cell, give two quick scores from 1 to 5 (gut reaction is fine):

- **Vastness:** does it feel huge, deep or far?
- **Stop:** would it make you stop and look?

A short note is welcome where something specific helps or hurts (for example "too symmetric" or "want to be on that ledge"). Picking your top 3 and bottom 3 also works if scoring all 16 is tedious.

**Please don't open `key.tsv` before rating.** It maps each cell to its template and awe metrics, and knowing them could bias your scores.

## What happens with the scores

The scores are logged here against `key.tsv`. Then I check which metrics track your scores (for example whether scale ratio predicts "vastness", or light contrast predicts "stop") and which don't. The results drive the next changes: template weights, targets for the metrics, and new devices where none of them explains a high score. The calibration is written up in this directory after each round.

Regenerate this sheet with:

```text
cargo run --release -p pigment-cli -- contact-sheet --out docs/visual-review/round-01/candidates-regions.png \
    --samples 10,3,6,21,12,1,30,17,9,0,26,16,8,33,14,41 --cell 480 --cols 4 [--view flat]
```
